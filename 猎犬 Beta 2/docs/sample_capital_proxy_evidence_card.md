## ② 资金子agent判断

### 600036 招商银行 — ❌ 不入池

**信号强度**：WEAK | **置信度**：0.30

- 低位置(0.21) + 微放量下跌(-3.27%) = 温和派发，非吸筹
- 融资几乎不变(-0.03%)，杠杆资金无态度
- 筹码仅微集中(-1.25%)，无信号意义
- 结论：**无人关注的冷淡状态**，不是聪明钱在偷偷建仓

### 300308 中际旭创 — 👀 观察

**信号强度**：MODERATE | **置信度**：0.45

- 但近5日急跌-11.74% + 融资撤退-5.03%，短期矛盾严重
- 关键问题：急跌是震仓洗浮筹 / 还是集中已完成、现在在派发？
- 等待止跌企稳确认

### 002130 沃尔核材 — 👀 观察

- ⚠️ 但筹码在分散(+8.94%)——散户抄底、机构出货，直接否定主动建仓
- 需等筹码由散转集 + 放量阳线确认

## 已知局限

1. **筹码数据时效滞后**：holder_change_ratio 基于定期报告（季报/年报），可能晚于实时行情1-3个月。中际旭创的-15.78%是最近一期数据，不代表当前筹码状态。
2. **大宗交易缺折溢价方向**：当前 block_trade 评分只看活跃度，不知溢价还是折价、不知买卖方。沃尔核材的大宗85分可能是机构接盘也可能是减持过桥，需定性补充。
3. **无量价背离检测**：证据包有量比和收益，但未自动检测"价升量缩/价跌量增"等背离模式，依赖子agent人工识别。
4. **无板块相对强度**：market_context 只有大盘北向，缺板块资金流对比。
5. **本批样本偏差**：3只各属不同行业（银行/通信/电子），结果不具统计意义。

## 对资金协议的改进建议

1. **block_trade 应加折溢价方向**：当前评分只反映活跃度，建议 stock_data.block_trade 返回时加 `premium_pct`（正=溢价/负=折价），让子agent直接判断大宗方向。
2. **holder_change 应标注数据截止日期**：当前返回 latest_change_ratio 但不含报告期，子agent不知道数据新旧，建议加 `report_period` 字段。
3. **建议在资金 SKILL 加一条"缩量见底模式"**：002130 的缩量(0.74)+极低位(0.026)+大宗活跃(85.0) 构成一个可识别的底部侦察模式。当前5把尺子没有覆盖"卖盘衰竭"的正面识别。
4. **data_quality=HIGH 何时启用**：建议当大宗方向已知 + 筹码可确认在报告期后趋势延续 + 量价结构清晰时，可升为 HIGH。
