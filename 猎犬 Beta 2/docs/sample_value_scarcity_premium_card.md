## 执行摘要

| 项目 | 数值 |
|------|------|
| 复盘样本 | AI算力链10控制者 |
| 5把尺入池 | 3只（30%） |
| 6把尺入池 | 3只（30%）—— 入池名单不变，但结论叙述变细 |
| 6把尺新增判断力 | 入池者的"稀缺性溢价"有证据支撑，不入池者的"叙事溢价"有明确证伪条件 |
| 关键改善 | 不入池理由从"太贵"升级为"稀缺性未转化为财务质量 / 溢价边界可证伪" |

**核心结论**：第6把尺改变的不是入池率（该入池的5把尺已入池），而是结论的证据质量和议价防御力。高PE入池者（中际旭创）现在附加了"稀缺性溢价证据链+证伪条件"，不再只是"PE虽高但合理"——这是 M2 决策层能据此做风控动作的差异。

## ① 原5把尺子的盲区

旧AI算力链控制者验证（2026-06-29）中，价值子agent用5把尺子得出"中际旭创/新易盛/沪电股份入池，其余7只不入池"的结论。从结果看入池名单本身正确，但缺少一个关键维度：

**5把尺对所有标的用同一估值标尺，无法区分"高PE合理"和"高PE纯叙事"的根本差异。**

具体盲区：

- **中际旭创（PE 89）**：5把尺说"global #1+ROE 17.5%+PEG<0.3=合理"，但没交代"89x PE对于光模块是否合理？溢价边界在哪？什么条件会证伪？"——入池理由不够深。
- **源杰科技（PE 598）** 和 **云南锗业（PE 4012）**：5把尺说"太贵/现金流差/叙事撑不起"，但没有用"稀缺性溢价框架"系统拆解：它们确实卡脖子，为什么不能像中际旭创一样获得高估值容忍？
- **有研新材（PE 190）**：央企InP量产，5把尺说"毛利率6.4%+现金流负=不入池"，但没有进一步追问"央企低效是否是稀缺性的成本？如果稀缺性不可替代，是否值得给更低质量容忍？"

## ② 第6把尺文本

> 摘录自价值 SKILL 心智模型 §6（2026-06-30 新增）

> **模型6：稀缺性溢价不是故事溢价**
>
> 卡脖子控制者、事实垄断、关键供应链节点、政策强约束资产，可以承受高于普通行业的估值；但必须同时检查盈利基础（ROE/毛利率）、现金流质量、客户粘性和替代风险。若只有叙事没有财务质量，属于故事溢价，不属于价值。

配套入池规则：

> - 高PE标的若具备稀缺性/垄断性，只能进入"稀缺性溢价观察"，不能因稀缺性直接判低估。
> - 必须回答"溢价由什么支撑、边界在哪里、什么证据会证伪"。

配套误判过滤器：

> - 把政策故事、卡脖子叙事、国产替代口号直接当安全边际。
> - 高PE但 ROE/现金流/毛利率没有支撑。
> - 稀缺性正在被新进入者、技术替代或客户降本破坏。

## ③ 旧样本复盘

### 样本1：中际旭创 300308 —— 稀缺性溢价合理

| 维度 | 旧5把尺 | 新6把尺 |
|------|---------|---------|
| 结论 | 入池，收入池理由碎片化 | 入池（稀缺性溢价观察），有系统证据链 |
| PE/PB | 89.6 / 38.7 | 同左 |
| ROE/毛利率 | 17.5% / 46.1% | 同左 |
| 核心判断 | global #1 + ROE 17.5% + PEG<0.3 + 现金流健康 | **稀缺性有盈利基础**：global #1客户粘性（英伟达/谷歌/微软）+ ROE>15%五年均值 + 毛利率>45%五年均值 + 现金流覆盖运营开支 |
| 溢价边界 | 未交代 | 支持溢价：17.5% ROE在A股光模块同行居首，46%毛利率说明定价权。溢价上限：若毛利率跌破35%或全球份额被中际光电/新易盛蚕食超过10%，溢价基础受损 |
| 证伪条件 | 无 |① 毛利率连续2季跌破35%；② YoY增速从+262%降至<50%；③ 云厂商自研光模块替代开始出样 |

**第6把尺差异**：旧卡只说"PE 89但合理"，新框架要求子agent交代"凭什么89x、什么时候不合理"。这对M2决策层有实质差异——M2可以盯着毛利率和份额变化做动态调整，而不是拿着"PE不高"这种一次性判断。

### 样本2：源杰科技 688498 —— 故事溢价（卡脖子叙事无盈利支撑）

| 维度 | 旧5把尺 | 新6把尺 |
|------|---------|---------|
| 结论 | 不入池，"598x PE需维持>100%增速3年" | 不入池，定性为**故事溢价** |
| PE | 598 | 同左 |
| 经营现金流/EPS | 22% | 同左 |
| 核心判断 | 太贵 | **稀缺性未转化为盈利**：100G/200G EML国产龙头，但ROE <5%（2024仅4.2%）+ 毛利率46%但净利率<15%（研发费用率>30%吞掉毛利）+ 经营现金流长期覆盖率低 |
| 稀缺性是否真实 | 未系统评估 | 真实——国产高速光芯片龙头，替代空间大。但稀缺性被高研发投入+低产能利用率消耗，尚未体现在利润表 |
| 故事溢价定性 | 无此维度 | **确认为故事溢价**：有卡脖子叙事，但财务质量（ROE<5, 现金流薄弱）不支撑当前598x PE。未来若毛利率>50%+现金流转正，可从故事溢价升级为成长溢价 |

**第6把尺差异**：旧卡说"太贵"就结束。新卡区分了"稀缺性真实但财务尚未兑现"和"稀缺性假象"，提供了**升级条件**（毛利率>50%+现金流转正）。M2可以跟踪这些转化条件，而不是只有"不能买"一个状态。

|------|---------|---------|
| 结论 | 不入池，"764亿市值对应年化<4000万利润" | 不入池，定性为**资源叙事溢价** |

## ④ 如何防止故事溢价

第6把尺不是把高PE标的都判低估，而是给子agent一套结构化的区分工具：

```
标的PE显著高于行业均值
    ├─ 具备稀缺性（卡脖子/垄断/关键节点）？
    │   ├─ 有 → 检查盈利基础（ROE>10%/毛利率>35%/现金流为正？）
    │   │       ├─ 三项都满足 → 稀缺性溢价合理（如中际旭创）
    │   │       ├─ 部分满足 → 稀缺性溢价观察，需要转化条件
    │   │       └─ 不满足 → 故事溢价（如源杰/云南锗业）
    │   └─ 无 → 高PE无稀缺性支撑 = 纯粹高估（用原5把尺排除）
    └─ PE接近行业均值 → 正常估值处理
```

**故事溢价的三种形态**：

| 形态 | 特征 | 实际案例 | 第6把尺识别方式 |
|------|------|---------|----------------|
| 资本密集溢价 | 稀缺性资产但研发/资本开支吞噬利润 | 源杰科技（研发率>30%吞噬毛利） | ROE<5% 或 经营现金流无法覆盖折旧 |
| 资源叙事溢价 | 资源垄断但盈利能力极低 | 云南锗业（4000万年利润 vs 764亿市值） | 盈利收益率<0.5%，且资源稀缺性已被完全定价 |
| 低效垄断溢价 | 垄断地位但运营低效 | 有研新材（毛利率6.4%，央企低效） | 稀缺性资产+央企/国企治理，ROE<5%且无修复路径 |

## §0 合规检查

| 检查项 | 合规？ | 证据 |
|--------|--------|------|
| 主agent/数据层有没有写"PE<X=低估"？ | ✅ 未写 | 模型6文本中无任何 "PE<X/PB<Y" 阈值条件 |
| 第6把尺是否替代了子agent判断？ | ✅ 未替代 | 只要求子agent"检查盈利基础/现金流/替代风险"——判断权仍在子agent |
| 稀缺性溢价是否等同于"高PE合理化"？ | ✅ 不是 | 要求同时列"支撑证据"和"证伪条件"，且高PE标的只能进入"稀缺性溢价观察"而非直接入池 |
| 第6把尺是否仍属于价值技能定位？ | ✅ 是 | 核心逻辑是"溢价要有财务质量背书"，不是偏离价值去追成长股 |
| 旧5把尺与新6把尺是否冲突？ | ✅ 不冲突 | 模型6是对模型1（低估≠便宜）在高PE场景的具体化补充，不改变模型1-5 |

## 已知局限

1. **本卡是复盘，非实盘**：数据来自2026-06-29旧验证，股价和财务数据可能已变化。实盘中子agent应按数据入口协议取最新值。
2. **ROE/毛利率阈值是定性指引，非机械规则**：模型6中"ROE>10%""毛利率>35%"是举例性质，子agent应根据行业特点做判断——光模块行业平均ROE~12%，所以17.5%属于强；央企InP行业无对标，6.4%就属于弱。
3. **第6把尺不覆盖所有高PE场景**：只适用于具备稀缺性/垄断性的标的。纯粹高成长（如SaaS/PaaS）的高PE应由成长技能处理——价值技能不跨界。
4. **证伪条件的动态性**：中际旭创的证伪条件（毛利率跌破35%/增速降至<50%/云厂商自研替代）需要持续跟踪。议题卡只记录静态判断点，M2需自行做动态更新。
5. **稀缺性的"被破坏"很难预判**：技术替代（如CPO取代EML）可能快速瓦解现有稀缺性，第6把尺要求子agent做替代风险分析，但替代何时发生本质上是预测——需要标注"推测"并控制仓位使用。
