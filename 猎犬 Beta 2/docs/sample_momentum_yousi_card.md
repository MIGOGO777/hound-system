## ② 映射环：强势板块名→游丝主题入参

### 为什么这里映射环更简单——但也不可省？

动量→游丝的映射环与催化→游丝不同：

- **催化→游丝**：催化产出"个股+事件"层面 → 需归纳成方向名 ← **必须补环**
- **动量→游丝**：动量产出本身就是"板块名"（如"消费电子/显示技术"）→ 方向名已经存在

但**映射环不可省的理由不同**：
- 动量子agent产出的"消费电子"是广义板块概念，而游丝需要的是**可拆解产业链的精准方向主题**
- 映射环在这里的作用是：把"消费电子板块"进一步聚焦到"游丝能挖的精确方向"
- 如果不经映射环，游丝直接搜"消费电子 产业链"，范围太大（包含手机/PC/TV/可穿戴/车载等），拆不出深层约束

### 映射实现

```
动量子agent产出："消费电子/显示技术"（板块级方向）
    ↓ 映射环：聚焦到可拆解产业链的精确子方向
    ↓ 基于动量最强的子板块（600060海信视像对应的Mini LED方向）
游丝主题入参："Mini LED显示技术产业链"
```

| 行动 | 说明 |
|------|------|
| 动量子agent产出 | "消费电子/显示技术"板块方向 |
| **映射环操作** | 根据板块内动量最强的细分方向（Mini LED显示），将方向名从板块级聚焦到产业链级 |
| 游丝入参 | "Mini LED显示技术" — 可作为"终端产品/终端市场"直接启动游丝第1轮需求增量搜索 |

> ⚠️ **区分映射环与认知判断**：聚焦到"Mini LED显示技术"不是因为主agent擅自判断它更好，而是因为动量子agent的输出中包含动量数据的来源（600060海信视像的RGB-Mini LED技术是板块动量信号的核心证据）。映射环的目标是把已有证据链中的精细方向提取出来，使游丝能够从"终端产品→价值链拆解→约束节点"一路追下去，而不是在"消费电子"这么宽的框里打转。

### 方向名

> **Mini LED显示技术** — 由动量子agent在"消费电子/显示技术"板块中识别的最强动量方向（600060海信视像60d +19.96%，RGB-Mini LED技术突破+618量额双冠+世界杯赛事催化）

### ⑤ 错配催化

**价值链矛盾链条**：

1. ✅ **产能错配**：Mini LED终端需求（+70%/年出货量增长）vs 驱动IC代工产能（成熟制程增长仅5-10%/年）→ 驱动IC可能在2026H2-2027H1出现结构性短缺
2. ✅ **认知错配**：市场聚焦"Mini LED电视销量"和"面板出货量"，但真正约束增长的是"每台电视需要2000-10000颗驱动IC"——这个需求爆发是乘数级的，主流覆盖关注不够
3. ✅ **国产替代空间**：国内驱动IC厂商合计份额<30%，但终端品牌（海信/TCL/京东方）均为中国企业 → 国产替代逻辑+客户锁定效应
4. ⚠️ **工艺错配**：Mini LED驱动IC需要40-90nm高压BCD工艺，不属于先进制程但产能紧张程度不亚于先进制程（成熟制程产能扩张慢、投资回报期长）

**催化强度**：高。产能+认知+国产替代三条错配同时成立。海信视像RGB-Mini LED的量产验证和2026世界杯赛事是短中期可见催化。

## 已知局限

1. **聚类样本局限**：仅50只样本中，2只属于消费电子板块（600060海信视像、600060本身），但泛消费电子相关标的占比较多。全市场扫描可能发现更多板块动量。
2. **板块动量 vs 个股动量**：本卡基于板块内代表性个股（600060海信视像）的动量特征来判断板块动量，更全面的判断需要板块指数或⊂3只以上同板块标的同步确认。
3. **方向聚焦的主观性边界**：从"消费电子/显示技术"聚焦到"Mini LED显示技术"的过程中，如果板块内同时有多个子方向（如OLED、Mini LED、Micro LED同时活跃），聚焦哪个方向需依赖动量子agent的输出粒度。
4. **SearXNG对专业显示产业链数据的覆盖**：驱动IC产能/代工工艺等专业数据可能不如半导体/光通信领域丰富，搜索结果深度受限。
5. **终端消费品需求波动风险**：消费电子属于可选消费品，全球经济波动对Mini LED TV出货量预测影响较大。
6. **技术迭代快**：显示技术迭代周期8-12个月，Mini LED的生命周期窗口有限（被Micro LED替代的风险），属中短期游丝（12-24月窗口）。

## 与 Recipe A（催化→游丝）的差异对比

| 对比维度 | 催化→游丝（Recipe A） | 动量→游丝（Recipe B） |
|---------|---------------------|---------------------|
| 上游产出 | 催化事件+个股（事件级） | 强势板块/方向（板块级） |
| **映射环难度** | **高**——须归纳"个股+事件"为方向名 | **低**——板块名已存在，仅需聚焦到可拆解方向 |
| 映射环不可省理由 | 不归纳方向名则游丝无有效输入 | 不经聚焦则游丝产业链范围太宽 |
| 方向类型 | 中短期事件驱动+周期驱动 | 中期趋势驱动+产业链成长周期 |
| 游丝约束类型 | 物理+时间双约束（造船产能） | 产能+技术约束（驱动IC代工瓶颈+芯片） |
| 评级 | S级（13/15，油运/能源运输） | A级（11/15，Mini LED显示技术） |
| 典型场景 | "什么事件触发→产业链深层约束在哪" | "哪里正在走强→产业链瓶颈在哪" |

> 补充联合用法：**催化→游丝 + 动量→游丝 可串联为"催化事件触发 → 方向确认 → 动量验证 → 游丝深挖"**。以本卡为例：催化子agent先发现油运方向（催化→游丝），动量若后续确认油运板块走强（动量→游丝），则双重验证该方向的产业链约束价值。两卡在方向上互补（油运 vs 显示技术），但机制上可以交叉验证同一方向。
