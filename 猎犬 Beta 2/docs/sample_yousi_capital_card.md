## 已知局限

1. **预取失败暴露数据链路脆弱性**：push2his.eastmoney.com 今日间歇不可达，导致 pre-fetch 阶段 8/10 标的返回 None。子agent自行 Bash 补取成功——证明"按需取"协议设计是不可或缺的兜底
2. **今日是极端行情日**：系统性板块暴跌 -2~5%，不适合做买入决策。正常交易日可能得到不同的资金分布
3. **无近5日序列数据**：recent_inflow_days 因 API 不可达未能获取，今日判断基于单日分钟级汇总 + 筹码/融资/大宗辅助

## 对深核子型协议的改进建议

1. **预取失败的标准处置**：当预取方法返回大面积 None 时，协议应规定"主agent通知子agent数据缺口，子agent自行补取"而非"主agent换方法重试"——因为子agent补取时带情境判断（知道自己在找什么），比主agent无差别重试高效
2. **深核子型应要求子agent报告"全局市场环境"**：资金子agent主动查看了板块跌幅和北向情绪，这对解释"为什么全部不买"至关重要——建议在资金SKILL的⑤输出契约加一条：`必须报告今日对应板块涨跌+大盘背景`
3. **沃尔核材是深核子型"双观察"的完美范例**：Task1价值判"合理但需观察"，Task2资金判"底部但无启动信号"——两只镜头从不同维度都给了"观察"而非"入池/不入池"，这种独立收敛比单一镜头的"入池"更有说服力
