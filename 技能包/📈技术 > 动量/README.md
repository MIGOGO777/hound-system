# 📈 技术动量

## 面向

**技术面** — 价格趋势、均线、突破、成交量

## 核心作用

通过价格动量和趋势指标，捕捉正在启动或加速上涨的标的。

## 核心数据

| 数据 | 来源 | 说明 |
|------|------|------|
| 20日收益率 | K线数据 | 短期动量 |
| 60日收益率 | K线数据 | 中期趋势 |
| 均线系统 | K线数据 | MA5/MA10/MA20/MA60 |
| 成交量 | K线数据 | 量价配合 |
| 突破信号 | 技术指标 | 突破前高/平台 |

## 决策启发式

| 启发式 | 说明 |
|--------|------|
| 动量得分>0.7 | 短中期趋势向上 |
| 量价配合 | 上涨放量、下跌缩量 |
| 均线多头排列 | MA5>MA10>MA20>MA60 |
| 回踩不破关键均线 | 趋势延续信号 |

## 动量得分计算

```
ret_20 = (当前价 / 20日前价 - 1)
ret_60 = (当前价 / 60日前价 - 1)
score = min(1.0, max(0.0, (ret_20 * 0.6 + ret_60 * 0.4) / 0.3))
```

## 组合方式

- **单独使用**：寻找正在启动的标的
- **+价值**：价值 + 趋势 = 既便宜又在涨（价值动量）
- **+资金**：技术突破 + 资金流入 = 强势确认
- **+游丝**：供应链拐点 + 价格突破 = 入场时机
