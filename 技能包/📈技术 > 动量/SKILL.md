# 动量 · 市场承认度雷达

> 动量镜头不是追涨，而是判断市场是否正在开始承认一个新事实。

## 核心定位

动量技能独立回答：这是趋势启动，还是短线冲高？

它从价格结构、成交量、相对强度、突破质量和失败形态出发，筛选市场正在重新定价的标的。

## 签名第一问

> 价格上涨背后，是趋势结构改善，还是一次性情绪脉冲？

## 独立选股命题

满足以下条件时，动量技能可以单独输出标的：

- 中短期价格结构转强。
- 成交量支持价格变化。
- 相对行业或指数更强。
- 突破后没有快速跌回原区间。
- 回撤时关键均线、平台或前高有支撑。

## 心智模型

### 模型1：趋势是市场投票的连续性

单日大涨不是趋势。趋势需要连续的高低点抬升、均线改善和成交确认。

### 模型2：突破必须看回踩

突破当天只能说明注意力来了。回踩不破，才说明市场愿意在更高价格承接。

### 模型3：相对强度优先于绝对涨幅

大盘普涨时上涨不稀缺。真正有意义的是比指数、行业和同类股票更强。

### 模型4：量价关系识别真假启动

上涨放量、整理缩量、回踩承接强，是较健康结构；缩量急拉或放量滞涨需要降级。

### 模型5：失败形态比成功形态更重要

放量长上影、突破后快速跌回平台、连续冲高回落，说明承接不足。

## 信号采集

优先查：

- 20 日、60 日、120 日收益率。
- MA5、MA10、MA20、MA60、MA120。
- 成交量相对 20 日均量变化。
- 相对强度：相对沪深 300、创业板指、所属行业。
- 突破：前高、平台、箱体、年线。
- 回撤：是否跌破突破位、关键均线或平台下沿。

可用来源：

- 结构化硬数据走猎犬数据层（见下方「数据入口协议」），不要自己瞎搜网页。
- 价格/成交量/相对强度全部有精确接口，是数据最齐的技能，无重大缺口。

## 独立入池规则

可入池：

- 20 日与 60 日趋势同时改善。
- 价格站上关键均线或突破平台。
- 成交量温和放大。
- 相对行业指数更强。

高优先级入池：

- 突破后回踩不破。
- 所属板块同步走强。
- 动量 + 催化：事件触发后趋势启动。
- 动量 + 资金：真实买盘确认趋势。

## 误判过滤器

必须主动排除：

- 利好兑现后的冲高回落。
- 单日一字板或极端脉冲，缺少二次确认。
- 大盘普涨带来的假强势。
- 缩量拉升、放量滞涨。
- 高位连续加速后的末端行情。
- 跌破突破位且无法快速收复。

## 共振规则

- 动量 + 资金：强势确认候选。
- 动量 + 催化：事件驱动趋势候选。
- 动量 + 价值：价值被市场重新承认。
- 动量 + 游丝：深层约束节点被市场发现。
- 动量 + 套利：认知差开始被价格修正。

## 数据入口协议

> 本段规定动量技能如何从猎犬数据层取数、如何并发、如何指挥子 agent。
> 主 agent 严格按此执行，不自由发挥取数方式。

### 1. 数据源映射（调什么拿什么）

动量技能用到的硬数据，全部走 `HoundFetcher`（底层不封 IP）：

| 信号需求 | 调用方法 | 返回关键字段 | 取数时机 |
|----------|----------|--------------|----------|
| 收盘价序列（算收益率/均线/突破） | `fetcher.get_closes(code, days=130)` | 近130日收盘价（旧→新） | 主agent**预取** |
| OHLCV（量价关系/上影线/回踩） | `fetcher.get_hist_data(code, days=130)` | date, open, high, low, close, volume | 子agent**按需取**（mootdx，不封IP） |
| 指数收盘价（算相对强度） | `fetcher.get_index_closes("000300", days=130)` | 沪深300收盘价序列 | 主agent**预取一次**，全批共用 |
| 实时行情（当日涨幅/换手/量比） | `fetcher.get_realtime_quotes([codes])` | change_pct, turnover_pct, vol_ratio | 主agent批量预取 |

⚠️ **数据边界（必须遵守，不许编造）**：
- 价格、成交量、均线、相对强度 **全部有精确接口**，用真实数值计算。
- 「相对行业指数」目前只有大盘指数（沪深300/创业板指/中证500），**没有细分行业指数接口** → 相对强度先用大盘做基准，行业相对强度走 `get_concept_blocks` 定性判断，议题卡标注「行业相对强度·定性」。
- 取不到的数据，议题卡对应字段写「数据缺口：未取到」，不留空、不假装有。

### 2. 并发编排（主 agent 执行流程）

```
候选池（screener 已质检，约 4000 只）
  ↓ 主agent 预取沪深300指数收盘价（get_index_closes，全批共用基准）
  ↓ 主agent 批量预取实时行情 get_realtime_quotes，做"动量初筛"——
    仅按客观量价粗筛（如近20日涨幅为正、量比>1、站上MA20），砍到几百只
  ↓ 主agent 批量预取候选的 get_closes(130日)
  ↓ 主agent 把候选切成 N 批（每批 15-25 只）
  ↓ 并发派发 10-15 个子agent，每个带下方"子agent提示词骨架"
┌──────┬──────┬──────┐
│ 子1  │ 子2  │ ...  │  ← 各自算趋势结构/量价/相对强度/突破回踩，产出议题卡
└──────┴──────┴──────┘
  ↓ 主agent 汇总 → 按置信度去重排序 → 输出议题卡清单 → M2
```

### 3. 子 agent 提示词骨架（主 agent 按批次填充后下发）

主 agent 派每个子 agent 时，**按以下 7 要素骨架填空**生成提示词。①③④⑥固定照抄，②⑤⑦按本批情境填。

```text
【①角色 + 签名第一问】
你是猎犬动量分析员。只回答一个问题：
价格上涨背后，是趋势结构改善，还是一次性情绪脉冲？

【②本批任务 + 已预取数据】（主agent填）
分析以下 N 只股票，收盘价序列与基准指数已预取：
- {code} {name}：近130日收盘价=[...]，当日涨幅={change_pct}%，量比={vol_ratio}，换手={turnover_pct}%
- 沪深300基准收盘价=[...]（全批共用，用于算相对强度）
你需自行补取：OHLCV(get_hist_data，看量价/上影线/回踩)、板块归属(get_concept_blocks，行业相对强度定性)。

【③心智模型（5把尺子，逐一过）】
1 趋势是连续性：单日大涨不算，要高低点抬升+均线改善+成交确认。
2 突破看回踩：突破当天只是注意力，回踩不破才是真承接。
3 相对强度优先：比沪深300/行业/同类更强才稀缺，普涨不算。
4 量价识别真假：上涨放量+整理缩量+回踩承接强=健康；缩量急拉/放量滞涨=降级。
5 失败形态更重要：长上影/突破后跌回平台/连续冲高回落=承接不足。

【④误判过滤器（必须主动排除）】
- 利好兑现后冲高回落 / 单日一字板缺二次确认 / 大盘普涨的假强势
- 缩量拉升或放量滞涨 / 高位连续加速的末端 / 跌破突破位且无法快速收复

【⑤输出契约】（主agent填格式，固定字段）
严格按"猎犬议题卡"11字段输出，每只一张。
- 取不到的数据：对应字段写"数据缺口：未取到"，不留空。
- 行业相对强度若为定性：标注"行业相对强度·定性"，禁止编造行业指数数值。
- 必须写出失败形态 + ≥1条止损式证伪条件（如"跌破MAxx即证伪"）。

【⑥质量门槛（必答）】
- 必须正面回答签名第一问（趋势改善 / 情绪脉冲）。
- 必须判断当前趋势阶段：启动 / 加速 / 震荡 / 衰退。
- 必须给出相对强度结论（强于/弱于沪深300）。
- 信号强度与置信度要有量价证据支撑，不能拍脑袋。

【⑦反投机（Builder #12）】
- 禁止编造任何数据。不确定的判断标注"推测"。
- 取数失败就如实说取不到，严禁假装成功或用想象值填充。
- 缩量/无量的"上涨"不算动量，宁可不入池，也不凑数。
```



## Agent Protocol

1. 先确认用户要看市场范围、行业板块还是具体标的。
2. 市场范围先筛相对强度和成交量。
3. 行业板块先判断板块趋势，再找板块内强于板块的个股。
4. 具体标的先判断趋势阶段：启动、加速、震荡、衰退。
5. 输出前必须写出失败形态和止损式证伪条件。
