# 🏛️ 政策光谱

## 面向

**政策面** — 国家战略、产业政策、政策导向

## 核心作用

判断A股标的是否符合国家战略方向，确定政策支持等级和投资优先级。

## 核心数据

| 数据 | 来源 | 说明 |
|------|------|------|
| 三象限映射 | 新闻分析 | 🟢要支持 / 🟡要稳定 / 🔴要退出 |
| 政策紧迫度 | 新闻分析 | 从频率/措辞/资源/关注度综合判断 |
| 产能过剩警示 | 行业数据 | 关注扩产计划/库存水平/价格走势 |
| PE锚 | 估值数据 | 🟡象限 PE<15正常 / 15-25偏高-10 / >25泡沫-20 |
| 数据源 | SearXNG API | `http://localhost:4000/search`（Google/Bing/DDG 多源聚合） |

## 决策启发式

| 启发式 | 说明 |
|--------|------|
| H-1 先定象限再看财报 | 财报再好的🔴行业也不碰 |
| H-2 PE容忍度=国家支持度 | 半导体PE 100+没人问询，房地产PE 5还被压 |
| H-3 辨识"帮倒忙"的坑 | 产能过剩的🟢 = 大坑 |
| H-4 国家焦虑期=超额收益期 | 政策越密集出台，对应方向越值得重仓 |

## 组合方式

- **单独使用**：顶层筛选，确定大方向
- **+游丝**：政策支持 + 供应链瓶颈 = 高确定性标的（chain模式）
- **+价值**：政策方向 + 低估值 = 安全边际
