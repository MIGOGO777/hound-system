# 📰 新闻催化

## 面向

**新闻面** — 财报预告、重大合同、股东增持、事件驱动

## 核心作用

捕捉时间敏感事件，发现即将或正在发酵的催化剂。

## 核心数据

| 数据 | 来源 | 说明 |
|------|------|------|
| 财报预告 | 公司公告 | 业绩预增/预减 |
| 重大合同 | 公司公告 | 中标/签约/合作 |
| 股东增持 | 公司公告 | 大股东/高管增持 |
| 股东户数变化 | 交易所 | 筹码集中度 |
| 热门板块 | 行情数据 | 板块涨幅>2% |

## 决策启发式

| 启发式 | 说明 |
|--------|------|
| 财报预增>30% | 业绩拐点信号 |
| 股东户数减少>5% | 筹码集中，主力吸筹 |
| 重大合同金额>年营收10% | 超预期利好 |
| 所在板块当日涨幅>2% | 板块热度高 |

## 催化剂类型

| 类型 | 信号 | 时效性 |
|------|------|--------|
| 📊 业绩催化 | 财报预告/快报 | 短期（1-2周） |
| 📝 合同催化 | 重大中标/签约 | 中期（1-3月） |
| 💎 筹码催化 | 股东户数减少 | 中期（1-3月） |
| 🔥 板块催化 | 所在板块活跃 | 短期（1-5天） |

## 组合方式

- **单独使用**：事件驱动策略
- **+资金**：资金流入 + 利好催化 = 爆发点
- **+光谱**：政策支持 + 催化剂 = 政策落地
- **+动量**：催化 + 趋势启动 = 强势爆发
