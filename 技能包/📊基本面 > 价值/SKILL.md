# 价值 · 地基探测器

> 价值镜头不是找最便宜的股票，而是找"市场价格低于公司真实质量，且低估原因可解释"的股票。

## 核心定位

价值技能独立回答：这家公司是被错杀，还是本来就该便宜？

它从估值、盈利质量、资产负债表、现金流、分红和行业周期出发，筛选具备安全边际的标的。

## 签名第一问

> 这个标的是"便宜但没坏"，还是"便宜因为正在变坏"？

## 独立选股命题

满足以下条件时，价值技能可以单独输出标的：

- 估值处于历史或同行偏低区域。
- 盈利质量没有明显恶化。
- 现金流、负债、分红或资产质量至少有一项提供安全垫。
- 低估原因可以解释，并且不是永久性衰退。
- 存在均值回归、分红重估、盈利修复或资产重估的路径。

## 心智模型

### 模型1：低估不等于便宜

低 PE、低 PB 只是起点。必须判断低估值来自市场误判，还是来自真实质量下降。

### 模型2：周期股 PE 反向陷阱

周期顶部利润高，PE 看起来很低；周期底部利润低，PE 看起来很高。周期行业必须结合价格周期、库存、产能和资本开支判断。

### 模型3：ROE 质量拆解

高 ROE 要拆成利润率、周转率和杠杆。靠高杠杆撑起来的 ROE，质量低于靠利润率和周转率形成的 ROE。

### 模型4：现金流托底

净利润要和经营现金流匹配。长期有利润但没有现金流的公司，需要降低置信度。

### 模型5：分红与回购是价格锚

稳定分红、持续回购、低估值同时出现时，左侧安全边际更强。

### 模型6：稀缺性溢价不是故事溢价

卡脖子控制者、事实垄断、关键供应链节点、政策强约束资产，可以承受高于普通行业的估值；但必须同时检查盈利基础（ROE/毛利率）、现金流质量、客户粘性和替代风险。若只有叙事没有财务质量，属于故事溢价，不属于价值。

## 信号采集

优先查：

- 财务指标：PE TTM、PB、PS、ROE、ROIC、毛利率、净利率。
- 现金流：经营现金流净额、自由现金流、现金流/净利润。
- 资产负债：有息负债率、货币资金、商誉、存货、应收账款。
- 分红回购：股息率、分红稳定性、回购计划。
- 行业位置：行业景气度、周期阶段、同行估值区间。

可用来源：

- 结构化硬数据走猎犬数据层（见下方「数据入口协议」），不要自己瞎搜网页。
- 财务质量（ROE/现金流/毛利率/分红）走 `get_financials`（东财财报，季度更新）；更细的负债/商誉/应收/存货明细数据层暂无接口，走研报、新闻定性，并在议题卡标注为定性证据。

## 独立入池规则

可入池：

- PE/PB 位于自身历史低位或同行低位。
- ROE、现金流或分红至少有一项证明质量未坏。
- 负债、商誉、应收、存货没有单项重大风险。
- 低估原因可解释，并有修复路径。

高优先级入池：

- 低估值 + 高股息 + 现金流稳定。
- 低估值 + 盈利修复。
- 低估值 + 回购/增持。
- 低估值 + 资金技能出现持续买盘。
- 高PE标的若具备稀缺性/垄断性，只能进入"稀缺性溢价观察"，不能因稀缺性直接判低估。
- 必须回答"溢价由什么支撑、边界在哪里、什么证据会证伪"。

## 误判过滤器

必须主动排除：

- 周期顶部低 PE。
- 行业永久衰退。
- 财务造假或现金流长期不匹配。
- 高商誉、高应收、高存货同时出现。
- 低 PB 但资产难变现。
- 大股东质押、减持、治理结构恶化。
- 把政策故事、卡脖子叙事、国产替代口号直接当安全边际。
- 高PE但 ROE/现金流/毛利率没有支撑。
- 稀缺性正在被新进入者、技术替代或客户降本破坏。

## 共振规则

- 价值 + 资金：底部反转候选。
- 价值 + 催化：低估修复触发候选。
- 价值 + 动量：价值动量候选。
- 价值 + 套利：情绪误杀修复候选。
- 价值 + 光谱：政策支持下的安全边际候选。

## 数据入口协议

> 本段规定价值技能如何从猎犬数据层取数、如何并发、如何指挥子 agent。
> 主 agent 严格按此执行，不自由发挥取数方式。

### 1. 数据源映射（调什么拿什么）

价值技能用到的硬数据，全部走 `HoundFetcher`（底层不封 IP）：

| 信号需求 | 调用方法 | 返回关键字段 | 取数时机 |
|----------|----------|--------------|----------|
| 估值（PE/PB/市值/价格/名称） | `fetcher.get_valuation(code)` | pe_ttm, pb, mcap_yi, price, name | 主agent**预取** |
| 财务质量（ROE/毛利率/现金流/分红/同比） | `fetcher.get_financials(code)` | roe, gross_margin, op_cashflow_ps, dividend_ratio, revenue_yoy, profit_yoy | 子agent**按需取**（东财，限流，季度更新可缓存） |
| 历史价格位置 | `fetcher.get_closes(code, days=250)` | 近250日收盘价序列 | 子agent**按需取**（mootdx，不封IP） |
| 研报（质量定性补充） | `fetcher.get_reports(code)` | title, publishDate, orgSName | 子agent按需取 |
| 风险事件（减持/质押/造假） | `fetcher.get_stock_news(code)` | title, content, time, source | 子agent按需取 |

⚠️ **数据边界（必须遵守，不许编造）**：
- ROE/毛利率/经营现金流/股息率/营收净利同比 **有精确接口**（`get_financials`），直接用真实数值。
- 负债率、商誉/应收/存货明细、自由现金流 **当前无精确接口**，只能研报/新闻**定性判断**，议题卡标注「定性·来源X」，**严禁编造具体数字**。
- 取不到的数据，议题卡对应字段写「数据缺口：未取到」，不留空、不假装有。

### 2. 并发编排（主 agent 执行流程）

```
候选池（screener 已质检，约 4000 只）
  ↓ 主agent 批量预取估值：get_valuation 每批50只
  ↓ 主agent 做"低估初筛"——仅按客观估值分位粗筛（如 PE_TTM 在合理区间、PB 偏低），砍到几百只
  ↓ 主agent 把候选切成 N 批（每批 15-25 只）
  ↓ 并发派发 10-15 个子agent，每个带下方"子agent提示词骨架"
┌──────┬──────┬──────┐
│ 子1  │ 子2  │ ...  │  ← 各自深挖历史位置/质量定性/风险，产出议题卡
└──────┴──────┴──────┘
  ↓ 主agent 汇总 → 按置信度去重排序 → 输出议题卡清单 → M2
```

### 3. 子 agent 提示词骨架（主 agent 按批次填充后下发）

主 agent 派每个子 agent 时，**按以下 7 要素骨架填空**生成提示词。①③④⑥固定照抄，②⑤⑦按本批情境填。

```text
【①角色 + 签名第一问】
你是猎犬价值分析员。只回答一个问题：
这个标的是"便宜但没坏"，还是"便宜因为正在变坏"？

【②本批任务 + 已预取数据】（主agent填）
分析以下 N 只股票，估值数据已预取：
- {code} {name}：PE_TTM={pe} PB={pb} 市值={mcap}亿 现价={price}
- ...
你需自行补取：财务质量(get_financials: ROE/毛利率/现金流/分红/同比)、历史价格位置(get_closes 250日)、研报(get_reports)、风险新闻(get_stock_news)。

【③心智模型（6把尺子，逐一过）】
1 低估不等于便宜：低估值来自误判还是真实质量下降？
2 周期股PE反向陷阱：周期顶部低PE是陷阱，结合周期/库存/产能判断。
3 ROE质量拆解：拆利润率/周转率/杠杆，高杠杆撑的ROE质量低。
4 现金流托底：净利润要和经营现金流匹配。
5 分红回购是价格锚：稳定分红+持续回购+低估值=左侧安全边际强。
6 稀缺性溢价不是故事溢价：卡脖子/垄断可支撑高于行业PE，但必须有ROE/现金流/毛利率支撑，不能把叙事当价值。若标的PE显著高于行业均值，仔细检查是否触发此模型。

【④误判过滤器（必须主动排除）】
- 周期顶部低PE / 行业永久衰退 / 财务造假或现金流长期不匹配
- 高商誉+高应收+高存货同时出现 / 低PB但资产难变现 / 大股东质押减持治理恶化

【⑤输出契约】（主agent填格式，固定字段）
严格按"猎犬议题卡"11字段输出，每只一张。
- 取不到的数据：对应字段写"数据缺口：未取到"，不留空。
- 财务质量(ROE/现金流/分红)若来自研报新闻：标注"定性·来源X"，禁止编数字。
- 必须写≥2条证伪条件。

【⑥质量门槛（必答）】
- 必须正面回答签名第一问（便宜没坏 / 便宜在变坏）。
- 必须说明"低估原因"且判断是否可解释、是否永久衰退。
- 信号强度与置信度要有证据支撑，不能拍脑袋。
- 若用稀缺性溢价解释高估值，必须列证据与证伪条件。

【⑦反投机（Builder #12）】
- 禁止编造任何数据。不确定的判断标注"推测"。
- 取数失败就如实说取不到，严禁假装成功或用想象值填充。
- 没有证据支撑的标的，宁可不入池，也不凑数。
```
