# 📊 基本面价值

## 面向

**基本面** — 财务指标、估值水平、盈利能力

## 核心作用

通过PE/PB/ROE等基本面指标，筛选低估值、高质量的标的。

## 核心数据

| 数据 | 来源 | 说明 |
|------|------|------|
| PE (TTM) | 财务数据 | 市盈率，越低越便宜 |
| PB | 财务数据 | 市净率，越低越便宜 |
| ROE | 财务数据 | 净资产收益率，越高越赚钱 |
| 股息率 | 分红数据 | 分红收益率，越高越有安全垫 |
| 净利润增速 | 财报 | 成长性指标 |

## 决策启发式

| 启发式 | 说明 |
|--------|------|
| PE<15 + PB<1.5 | 低估值区间，具备安全边际 |
| PE>0 前置条件 | 排除亏损股（负PE无意义） |
| ROE>15% | 盈利能力强，护城河宽 |
| 股息率>3% | 分红稳定，下跌有托底 |

## 阈值设置

| 指标 | 阈值 | 信号强度 |
|------|------|----------|
| PE<8 | EXTREME | 极度低估 |
| PE<12 | STRONG | 明显低估 |
| PE<15 | MODERATE | 合理偏低 |
| PE>15 | WEAK | 不符合价值标准 |

## 组合方式

- **单独使用**：寻找被低估的优质标的
- **+动量**：价值 + 趋势 = 既便宜又在涨（价值动量）
- **+光谱**：政策支持 + 低估值 = 安全边际
- **+资金**：低估值 + 资金流入 = 底部信号
