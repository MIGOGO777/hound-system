# 💰 资金流向

## 面向

**资金面** — 融资余额、北向资金、大宗交易

## 核心作用

跟踪聪明钱（机构、外资、大股东）的流向，发现资金正在布局的标的。

## 核心数据

| 数据 | 来源 | 说明 |
|------|------|------|
| 融资余额变化 | 交易所 | 杠杆资金动向 |
| 北向资金 | 沪深港通 | 外资动向 |
| 大宗交易 | 交易所 | 机构/大股东交易 |
| 龙虎榜 | 交易所 | 游资/机构席位 |
| 主力资金流 | 盘口数据 | 大单净流入 |

## 决策启发式

| 启发式 | 说明 |
|--------|------|
| 融资余额增长>5% | 杠杆资金看好 |
| 北向资金连续流入 | 外资持续布局 |
| 大宗交易溢价成交 | 机构愿意高于市价买入 |
| 龙虎榜机构席位买入 | 机构主动建仓 |

## 信号强度

| 条件 | 强度 |
|------|------|
| 融资+北向+大宗三重确认 | EXTREME |
| 任意两项确认 | STRONG |
| 仅一项确认 | MODERATE |
| 无资金信号 | WEAK |

## 组合方式

- **单独使用**：跟踪聪明钱动向
- **+价值**：低估值 + 资金流入 = 底部信号
- **+动量**：技术突破 + 资金流入 = 强势确认
- **+催化剂**：资金流入 + 利好催化 = 爆发点
