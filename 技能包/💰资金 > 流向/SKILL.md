# 资金 · 真实买盘侦测器

> 资金镜头不是看"今天净流入多少"，而是判断进来的钱是否真实、持续、有质量。

## 核心定位

资金技能独立回答：进来的是长钱，还是短钱？

它从资金类型、持续性、席位质量、交易价格、筹码变化和价格位置出发，筛选真实买盘正在进入的标的。

## 签名第一问

> 这笔资金是在主动建仓，还是短线扰动、对倒或情绪交易？

## 独立选股命题

满足以下条件时，资金技能可以单独输出标的：

- 有可验证的资金流入或筹码集中迹象。
- 流入具备持续性，不只是单日脉冲。
- 资金类型质量较高，例如超大单(机构大资金)、产业资本、融资中长期增加。
- 买入价格没有明显透支短期空间。
- 资金行为与价格结构不矛盾。

## 心智模型

### 模型1：资金质量高于资金数量

同样是流入，长线资金、产业资本和机构席位的含义高于短线游资脉冲。

### 模型2：持续性比单日强度重要

连续小幅流入通常比一天巨量流入更值得跟踪。

### 模型3：位置决定含义

底部放量吸筹、突破放量确认、高位放量滞涨，含义完全不同。

### 模型4：大宗交易看折溢价和对手方

溢价成交、机构接盘、锁定期更积极；折价成交可能是减持或流动性转移。

### 模型5：融资盘是双刃剑

融资余额增加可说明风险偏好提升，也可能代表拥挤交易和杠杆过热。

## 信号采集

优先查：

- 资金行为代理证据包：量价持续性、价格位置、融资变化、大宗折溢价、筹码集中度。
- 市场背景：大盘北向情绪（仅作背景，非个股信号）。

可用来源：

- 结构化硬数据走猎犬数据层（见下方「数据入口协议」），不要自己瞎搜网页。
- 资金证据包走 fetcher.get_capital_evidence(code)，覆盖量价/位置/融资/大宗/筹码/市场背景/概念。
- 融资/大宗/筹码等细项信号有精确接口；龙虎榜机构席位暂无封装，走研报新闻定性补充。
- 旧主力资金流 (push2his) 已停止，不再作为主信号。

## 独立入池规则

可入池：

- 个股主力资金（超大单）连续流入。
- 融资余额温和持续增加，且价格未高位过热。
- 大宗交易溢价成交或机构接盘。
- 股东户数下降，筹码集中。

高优先级入池：

- 底部区域资金持续流入。
- 资金流入 + 价格突破。
- 资金流入 + 明确催化。
- 资金流入 + 低估值。

## 误判过滤器

必须主动排除：

- 单日主力净流入造成的噪音。
- 对倒和盘口资金假象。
- 高位融资快速增加。
- 大宗交易折价减持。
- 龙虎榜短线游资隔日兑现。
- 把大盘北向情绪硬套到个股（北向是大盘背景，无个股区分度）。

## 共振规则

- 资金 + 价值：底部反转候选。
- 资金 + 动量：强势确认候选。
- 资金 + 催化：事件爆发候选。
- 资金 + 套利：情绪修复候选。
- 资金 + 光谱/游丝：产业机会被资金承认。

## 数据入口协议

> 本段规定资金技能如何从猎犬数据层取数、如何并发、如何指挥子 agent。
> 主 agent 严格按此执行，不自由发挥取数方式。

### 1. 数据源映射（调什么拿什么）

资金技能用到的硬数据，全部走 `HoundFetcher`（底层不封 IP）：

| 信号需求 | 调用方法 | 返回关键字段 | 取数时机 |
|----------|----------|--------------|----------|
| **资金证据包（主入口）** | `fetcher.get_capital_evidence(code)` | volume_price/position/margin/block_trade/holder/market_context/concept/data_quality/missing | 子agent**按需取** |
| 融资余额变化 | `fetcher.get_margin_change(code)` | 融资余额环比变化%（正=加杠杆） | 子agent按需取 |
| 大宗交易活跃度 | `fetcher.get_block_trade(code)` | 0-100评分（溢价/量加权） | 子agent按需取 |
| 筹码集中（股东户数） | `fetcher.get_holder_change(code)` | holder_num, change_ratio（负=集中） | 子agent按需取 |
| 板块资金（行业方向用） | `fetcher.get_concept_blocks(code)` | boards, change_pct, concept_tags | 子agent按需取 |
| 价格位置（判断吸筹/突破/高位） | `fetcher.get_closes(code, days=120)` | 近120日收盘价 | 主agent**预取** |
| 大盘北向情绪（背景，非个股） | `fetcher.get_market_north_sentiment()` | hgt_yi, sgt_yi, total_yi（整体净流入） | 主agent**预取一次**，全批共用 |

⚠️ **数据边界（必须遵守，不许编造）**：
- **资金证据包是资金技能的个股主信号**：量价持续性(volume_price) + 价格位置(position) + 融资(margin) + 大宗(block_trade) + 筹码(holder) = 多源代理证据链。子agent据此判断"主动建仓 vs 短线扰动"。
- ⚠️ 旧主力资金流 (push2his eastmoney stock_fund_flow_120d) 已停止，不可用。资金子agent不得假设存在 main_net_yi/super_net_yi/recent_inflow_days 字段。
- ⚠️ **个股每日北向流入已于 2024-08 起停止实时披露** → `market_context` 返回的是**沪深股通大盘整体**净流入，scope 字段已标注 `market_only_not_individual`。**只作市场情绪背景，绝不可当个股信号**。
- **龙虎榜机构席位、游资席位 当前无封装接口** → 只能研报/新闻**定性判断**，议题卡标注「席位·定性·来源X」，**严禁编造席位名称或金额**。
- 取不到的数据，议题卡对应字段写「数据缺口：未取到」，不留空、不假装有。
- **大宗交易(block_trade)约束**：`latest_premium_pct > 0` 才可支持"接盘/吸筹"推断；折价大宗（premium_pct < 0）必须警惕减持。方向判断由子agent根据数据作，不写死在数据层。
- **大宗交易时效性纪律**：
  - `is_stale=True` 或 `within_1y=False`：大宗数据来自超过1年前的交易，只能写"历史大宗背景"，不得作为"当前接盘/当前吸筹"的主证据。
  - `age_days` 必须在议题卡里显式引用，尤其当 `age_days > 365`。
  - `latest_premium_pct > 0` 且 `within_1y=True` 才可作为"近期溢价接盘"的支持证据之一。
- **筹码(holder)约束**：必须引用 `latest_date`/`report_period`，标注"季度级滞后"，不得当实时筹码使用。

### 2. 并发编排（主 agent 执行流程）

```
候选池（screener 已质检，约 4000 只）
  ↓ 主agent 预取一次大盘北向情绪 get_market_north_sentiment（全批共用·仅作市场背景）
  ↓ 主agent 批量预取候选的 get_closes(120日)，判断价格位置（底部/平台/高位）
  ↓ 主agent 做"资金初筛"——客观粗筛（如近期有放量、不在明显高位），砍到几百只
  ↓ 主agent 把候选切成 N 批（每批 15-25 只）
  ↓ 并发派发 10-15 个子agent，每个带下方"子agent提示词骨架"
┌──────┬──────┬──────┐
│ 子1  │ 子2  │ ...  │  ← 各自查主力资金流/融资/大宗/筹码，判断资金质量与持续性，产出议题卡
└──────┴──────┴──────┘
  ↓ 主agent 汇总 → 按置信度去重排序 → 输出议题卡清单 → M2
```

主 agent 派每个子 agent 时，**按以下 7 要素骨架填空**生成提示词。①③④⑥固定照抄，②⑤⑦按本批情境填。

## Agent Protocol

1. 先确认用户要看市场范围、行业方向还是具体标的。
2. 市场范围先找连续资金流入和筹码集中。
3. 行业方向先看板块资金，再看个股资金。
4. 具体标的先判断资金类型、持续性和价格位置。
5. 输出前必须区分长钱、短钱和噪音资金。
