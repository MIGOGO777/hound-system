# 游丝 · 跨行业深层约束

## 面向

**深层约束面** — 价值链脉络、卡脖子环节、扩张瓶颈、替代难点、隐形控制者。

## 核心作用

沿着需求增量向价值链深处追踪，挖掘各行业中最难扩张、最难替代、最容易被市场忽视的关键约束节点。

## 约束类型

| 类型 | 说明 |
|------|------|
| 物理约束 | 材料、设备、产能、良率、地理位置 |
| 时间约束 | 扩产、认证、临床、客户导入、建设周期 |
| 牌照约束 | 监管许可、资质目录、准入门槛 |
| 信任约束 | 历史交付、品牌、客户关系、供应稳定性 |
| 网络约束 | 渠道、接口、标准、节点、生态位置 |
| 认知约束 | 市场暂时忽视，但产业链实际离不开 |

## 核心数据

| 数据 | 来源 | 说明 |
|------|------|------|
| 需求增量 | 财报、公告、政策、招投标 | 钱、订单、预算、用户往哪流 |
| 价值链地图 | 年报、招股书、行业报告 | 从终端到深层投入品/资质/渠道 |
| 控制者证据 | 市占率、专利、资质、客户披露 | 谁真正控制约束 |
| 扩张难度 | 环评、认证、产能、电话会 | 约束持续多久 |
| 替代路径 | 技术路线、竞争扩产、客户自研 | 论题如何被证伪 |

## 决策启发式

| 启发式 | 说明 |
|--------|------|
| 签名第一问 | 需求往哪流？价值链哪里最难扩张、最难替代、最容易被忽视？ |
| 三层下钻 | 不停在龙头或第一层供应商，至少向下追三层 |
| 控制者优先 | 先找谁控制约束，再看有没有上市映射 |
| 错配验证 | 深层重要性和市场注意力之间必须存在落差 |
| 证伪先行 | 每个游丝结论都要写清楚降级/退出条件 |

## 决策终止条件

| 信号 | 判定 |
|------|------|
| Go | 需求增量明确 + 约束强 + 控制者清晰 + 错配存在 |
| 观察 | 约束存在，但控制者/估值/催化不清晰 |
| No-Go | 无真实约束 / 容易替代 / 无定价权 / 已充分定价 |

## 组合方式

- **单独使用**：跨行业深层约束挖掘。
- **+光谱**：光谱找大方向，游丝挖深约束。
- **+技术**：深层约束确认后，用价格突破寻找入场时机。
- **+价值**：约束节点确认后，检查价格是否给出安全边际。
