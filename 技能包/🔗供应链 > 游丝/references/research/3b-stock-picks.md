## 一、概览

### 人物画像
- **身份**: 前 Reddit WSB 用户，现 X/Twitter 上的 AI 半导体供应链分析师（~850K followers）
- **核心方法论**: "瓶颈理论"（Bottleneck Theory）—— 不买铲子卖家（$NVDA），买铲子卖家的材料供应商
- **自称年化回报**: +122%（1Y），YTD 据称>4500%（HTX报道）
- **SignalSnitch 客观评级**: **51%** 胜率（464 resolved calls, 235W/229L），排名 #45/所有追踪交易者
- **最准标的**: $GOOG (90% 准确率)
- **风格**: 基本面驱动 + 深度供应链 BOM 分析 + 期权波动率意识

### 核心投资框架: "多跳供应链映射"
1. 从 hyperscaler 资本支出承诺出发（如 $GOOGL $175-185B capex）
2. 映射到所需的硬件（$LITE OCS for TPU, $AAOI transceiver for clusters）
3. 映射到所需元器件（InP 激光 → InP 衬底 → InP 原料）
4. 识别每层中垄断/瓶颈的环节 → 那就是交易标的

## 六、决策终止条件签名 (Go/No-Go 信号)

### GO 信号（买入条件）
| # | 信号 | 描述 |
|---|------|------|
| G1 | **瓶颈识别完成** | 找到供应链中单一/双头垄断的环节，且该环节的上游需求正在指数级增长（AI Capex） |
| G2 | **市值 < $3B** | 目标公司在识别时市值低于 $30亿，才有足够的重估空间 |
| G3 | **BOM 占比小** | 目标产品在 hyperscaler BOM 中占比小（~8-12%），意味着客户会支付溢价通过瓶颈 |
| G4 | **功能性垄断** | 纯正标的（非多元化集团拖累）；结构性护城河由专利/工艺 IP 保护；无近期合格替代品 |
| G5 | **催化剂窗口明确** | OFC/GTC/JPM fireside/MSCI rebalance/earnings 等已知催化剂前入场 |
| G6 | **融资结构干净** | 非 ATM 融资；strategic investment/convertible notes 更优 |
| G7 | **TAM 扩展 > burn rate** | 前沿技术不能用当前收入/利润建模；远期 TAM 扩展是关键（CPO 2027-2028） |

### NO-GO 信号（不买/避开条件）
| # | 信号 | 描述 |
|---|------|------|
| N1 | **ATM 稀释** | 大规模活跃 ATM + 高管 SBC 奖励同时存在 = 结构性熊市信号（$IREN, $SLNH, $BKKT） |
| N2 | **市值已大幅上涨** | 如 $AXTI 到 $5B+ MC 后不再推荐新买入 |
| N3 | **宏观不确定性高** | 伊朗冲突 + 特朗普关税不确定性 = 不使用杠杆，保留 15-30% 现金/对冲 |
| N4 | **管理层记录不良** | CEO 前公司归零记录（$BKKT/$ASST → $IREN 类比） |
| N5 | **TA 驱动而非基本面驱动** | 没有基本面 + 催化剂 + 宏观配合的 TA 是"占星术" |
| N6 | **供应链层级混淆** | 将衬底 vs. 外延片 vs. 模块混为一谈；错误理解公司实际在供应链中的位置 |
