# 🎭 情绪套利

## 面向

**情绪面** — 舆情热度、机构调研、AH溢价、市场情绪

## 核心作用

捕捉跨市场/跨渠道的信息差，发现市场情绪与基本面背离的机会。

## 核心数据

| 数据 | 来源 | 说明 |
|------|------|------|
| 舆情热度 | 新闻/社交媒体 | 近7天新闻数量 |
| 机构调研密度 | 交易所 | 近30天研报/调研数量 |
| AH溢价 | 港股/A股 | AH股价格差异 |
| 融资融券余额 | 交易所 | 做多/做空情绪 |
| 换手率 | 行情数据 | 交易活跃度 |

## 决策启发式

| 启发式 | 说明 |
|--------|------|
| 舆情热度>0.5 | 市场关注度高 |
| 机构调研密集 | 机构正在研究，可能建仓 |
| AH溢价收窄 | 估值回归信号 |
| 研报数量≠研报质量 | 需结合评级判断 |

## 情绪热度计算

```
近7天新闻数 / 10 = 舆情热度 (0-1)
>0.7 = 高热度
0.4-0.7 = 中热度
<0.4 = 低热度
```

## 组合方式

- **单独使用**：信息差套利
- **+催化剂**：情绪高涨 + 利好催化 = 追涨
- **+价值**：情绪低迷 + 基本面好 = 左侧布局
- **+资金**：情绪反转 + 资金流入 = 底部反转
