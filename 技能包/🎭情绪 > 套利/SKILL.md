# 套利 · 认知错配扫描器

> 套利镜头不是寻找"别人不知道的秘密"，而是寻找事实变化和市场认知之间的时间差。

## 核心定位

套利技能独立回答：这里是真信息差，还是我以为别人不知道？

它从跨市场价差、跨品种价差、上下游传导、舆情和基本面背离、机构调研和市场反应错位出发，筛选认知尚未同步的标的。

## 签名第一问

> 哪个市场、哪类投资者或哪条信息链已经反应了变化，而 A 股标的还没反应？

## 独立选股命题

满足以下条件时，套利技能可以单独输出标的：

- 存在可描述的认知差、信息差或定价差。
- 差异来自真实事实，而不是主观想象。
- 有路径让差异被市场修正。
- 修正窗口不是无限期。
- 标的和事实变化之间有清晰映射。

## 心智模型

### 模型1：信息差必须有参照市场

参照可以是港股、美股、可转债、期货、上游价格、下游订单、同行股价或机构调研。

### 模型2：情绪低迷不等于错杀

市场悲观可能是错杀，也可能是基本面真的变差。必须验证事实。

### 模型3：隐性受益比显性热门更有错配

热门概念的龙头常被快速定价，真正的套利机会可能在供应商、耗材、渠道、牌照或小业务线。

### 模型4：调研热度是早期注意力信号

机构调研增加但股价未反应，可能说明研究开始、交易尚未发生。

### 模型5：价差长期存在时不能默认回归

AH 溢价、折价、转债溢价可能长期存在。必须找到收敛触发器。

## 信号采集

优先查：

- AH 溢价、A/B 价差、可转债/正股偏离。
- 港股、美股、期货、商品价格对 A 股映射。
- 舆情热度和股价反应。
- 机构调研密度、研报覆盖变化。
- 产业链上下游价格和订单变化。
- 同行业公司涨跌分化。

可用来源：

- 结构化硬数据走猎犬数据层（见下方「数据入口协议」），不要自己瞎搜网页。
- 可转债/正股错配（集思录，需登录）、机构调研热度（东财）、AH 溢价（东财）三类**有精确接口**。
- 港股/美股映射、上下游价格暂无接口 → 走 SearXNG 搜索或定性，议题卡标注。

## 独立入池规则

可入池：

- 参照市场已反应，目标标的未充分反应。
- 事实变化可验证。
- 有催化或传播路径让认知差收敛。
- 风险收益不依赖永久价差回归。

高优先级入池：

- 事实变化强 + 市场关注低。
- 机构调研升温 + 股价未反应。
- 产业链真实受益 + 热点尚未扩散。
- 套利 + 价值：情绪误杀候选。
- 套利 + 动量：认知差开始收敛。

## 误判过滤器

必须主动排除：

- 伪信息差，市场早已知道。
- 情绪低迷有真实基本面原因。
- AH 溢价长期存在，没有收敛触发器。
- 调研多但没有买盘。
- 热点映射牵强，业务占比太小。
- 概念股蹭热点，没有收入或利润贡献。

## 共振规则

- 套利 + 价值：误杀修复候选。
- 套利 + 动量：认知差开始修正。
- 套利 + 资金：聪明钱提前进入。
- 套利 + 催化：信息差有触发器。
- 套利 + 游丝：市场没看见的深层约束。

## 数据入口协议

> 本段规定套利技能如何从猎犬数据层取数、如何并发、如何指挥子 agent。
> 主 agent 严格按此执行，不自由发挥取数方式。

### 0. 集思录 cookie 前置检查（你要的"通知环节"，必做）

套利依赖集思录可转债数据，而集思录**需要登录**。每次套利涉及转债前，
主 agent **先调一次** `fetcher.get_convertible_bonds()` 探测：

```
主agent 调 get_convertible_bonds()
  ├─ 正常返回（300+ 条）→ cookie 有效，继续后续流程
  └─ 抛 JisiluCookieError → 立即停下，明确通知 sui：
     "🍿 套利要用集思录可转债数据，但检测到未登录 / cookie 失效。
      请在本地 Chrome 打开 https://www.jisilu.cn 登录，登录后告诉我，我重试。"
     —— 绝不静默跳过转债、绝不假装没有这一信号（Builder #12 失败显性化）
```

⚠️ cookie 解密只在 **sui 本机（已登录集思录的 Chrome）** 有效；换机器/上服务器此路断，需另配 cookie。

### 1. 数据源映射（调什么拿什么）

套利技能的硬数据走 `HoundFetcher`（底层不封 IP）：

| 信号需求 | 调用方法 | 返回关键字段 | 取数时机 |
|----------|----------|--------------|----------|
| 可转债/正股错配 | `fetcher.get_convertible_bonds()` | bond_name, stock_name, premium_rt, dblow, convert_value | 主agent**预取一次**（全市场转债） |
| 机构调研热度 | `fetcher.get_institution_research(code)` | survey_date, org_num（机构家数） | 子agent**按需取** |
| AH 溢价（跨市场价差） | `fetcher.get_ah_premium()` | name, premium_rt（负=A股折价）, a_price, h_price | 主agent**预取一次**（全市场AH） |
| 同行分化（错配定位） | `fetcher.get_concept_blocks(code)` | boards, change_pct, concept_tags | 子agent按需取 |
| 舆情误杀（情绪面） | `fetcher.get_stock_news(code)` | title, content, time | 子agent按需取 |
| 价格反应（验证未反应） | `fetcher.get_closes(code, days=120)` | 近120日收盘价 | 子agent按需取 |

⚠️ **数据边界（必须遵守，不许编造）**：
- 可转债、机构调研、AH 溢价 **有精确接口**，用真实数值。
- 集思录可转债**需登录**：未登录抛 JisiluCookieError → 按上方 §0 通知 sui，**严禁用 30 条残缺数据假装全量**。
- **港股/美股逐只映射、上下游价格传导 当前无接口** → 走 SearXNG/WebFetch 定性或暂缺，议题卡标注「跨市场映射·定性·来源X」，**严禁编造港股价格或价差**。
- AH 溢价只覆盖**同时 A+H 上市**的约 100 只，不覆盖纯 A 股。
- 取不到的数据，议题卡对应字段写「数据缺口：未取到」，不留空、不假装有。

### 2. 并发编排（主 agent 执行流程）

```
候选池（screener 已质检，约 4000 只）
  ↓ §0 主agent 先探集思录 cookie（get_convertible_bonds），失效则通知 sui 登录后再继续
  ↓ 主agent 预取两份全市场错配表：可转债(premium_rt/dblow) + AH溢价(premium_rt)
  ↓ 主agent 做"套利初筛"——客观粗筛出错配候选：
    · 转债：低溢价率 + 低双低值（攻守兼备）
    · AH：A股相对H股折价（premium_rt 为负或偏低）
    · 圈定这些错配标的对应的正股/A股，砍到几十~几百只
  ↓ 主agent 把候选切成 N 批（每批 15-25 只）
  ↓ 并发派发 10-15 个子agent，每个带下方"子agent提示词骨架"
┌──────┬──────┬──────┐
│ 子1  │ 子2  │ ...  │  ← 各自查调研热度/舆情/同行分化/价格反应，判断是真错配还是伪信息差
└──────┴──────┴──────┘
  ↓ 主agent 汇总 → 按置信度去重排序 → 输出议题卡清单 → M2
```

### 3. 子 agent 提示词骨架（主 agent 按批次填充后下发）

主 agent 派每个子 agent 时，**按以下 7 要素骨架填空**生成提示词。①③④⑥固定照抄，②⑤⑦按本批情境填。

```text
【①角色 + 签名第一问】
你是猎犬套利分析员。只回答一个问题：
这里是真信息差，还是我以为别人不知道？
即：哪个市场/哪类投资者/哪条信息链已反应了变化，而这个 A 股标的还没反应？

【②本批任务 + 已预取数据】（主agent填）
分析以下 N 只股票，错配信号已预取：
- {code} {name}：错配类型={转债低溢价/AH折价}，转债溢价率={premium_rt}%（或AH溢价率={premium_rt}%）
你需自行补取：机构调研热度(get_institution_research看org_num与日期)、舆情(get_stock_news)、同行分化(get_concept_blocks)、价格反应(get_closes看是否已动)。

【③心智模型（5把尺子，逐一过）】
1 信息差必须有参照市场：港股/转债/期货/上游价/下游订单/同行/机构调研，说清参照物。
2 情绪低迷≠错杀：悲观可能是错杀，也可能基本面真变差，必须验证事实。
3 隐性受益>显性热门：龙头被快速定价，错配常在供应商/耗材/渠道/牌照/小业务线。
4 调研热度是早期注意力：机构调研升温但股价未动 = 研究开始、交易未发生。
5 价差长期存在时不默认回归：AH溢价/转债溢价可能长期存在，必须找到收敛触发器。

【④误判过滤器（必须主动排除）】
- 伪信息差（市场早知道）/ 情绪低迷有真实基本面原因 / AH溢价长期存在无收敛触发器
- 调研多但没买盘 / 热点映射牵强业务占比太小 / 概念股蹭热点无收入利润贡献

【⑤输出契约】（主agent填格式，固定字段）
严格按"猎犬议题卡"11字段输出，每只一张。
- 取不到的数据：对应字段写"数据缺口：未取到"，不留空。
- 跨市场映射若为定性：标注"跨市场映射·定性·来源X"，禁止编造港股价格/价差。
- 必须说清"参照物 + 差异 + 收敛路径 + 收敛触发器"，缺一不可入池。
- 必须正面回答"为什么市场还没反应"，并写≥2条证伪条件。

【⑥质量门槛（必答）】
- 必须正面回答签名第一问（真信息差 / 自以为的信息差）。
- 必须指明参照市场/参照物——没有参照物的"错配"不成立。
- 必须给出收敛触发器——没有触发器的价差不能默认回归。
- 信号强度与置信度要有错配证据支撑，不能拍脑袋。

【⑦反投机（Builder #12）】
- 禁止编造任何数据。不确定的判断标注"推测"。
- 取数失败就如实说取不到，严禁假装成功或用想象值填充。
- 集思录未登录就停下通知 sui，严禁用 30 条残缺数据假装全量。
- 找不到参照物或收敛触发器的"错配"，宁可不入池，也不凑数。
```

## Agent Protocol

1. 先确认用户要看市场范围、主题映射还是具体标的。
2. 市场范围先找跨市场、跨品种或跨行业价差。
3. 主题映射先找真正受益链条，再找关注度不足的上市公司。
4. 具体标的先说明参照物、差异、收敛路径。
5. 输出前必须回答"为什么市场还没反应"。
